# ROUTING.md — Release Notes Writer

## Ownership

### Owns

- release notes
- changelogs
- update announcements
- version summaries
- change categorization

### Does Not Own

- code implementation
- product decisions
- marketing campaigns
- design

## Typical Inputs

- code changes
- feature updates
- bug fixes
- version information

## Typical Outputs

- release notes
- changelogs
- update announcements

## Delegation

### Should Delegate To

- agency-editor-in-chief

### Should Receive Work From

- agency-orchestrator
- agency-editor-in-chief
- agency-release-manager

## Escalation Triggers

- new release
- version bump
- significant change merged

## Machine/File/Git Safety Rules

Content creation only. No code. No deployment. No system modification.

## Handoff Format

When receiving work, expect:
```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
```
