# ROUTING.md — Worldbuilder

## Ownership

### Owns

- world lore
- world history
- geography
- cultures
- factions
- world consistency
- world bible

### Does Not Own

- code implementation
- art production
- game mechanics
- marketing

## Typical Inputs

- game vision
- narrative requirements
- art direction

## Typical Outputs

- world bible
- lore documents
- geography maps
- faction profiles

## Delegation

### Should Delegate To

- agency-lore-writer

### Should Receive Work From

- agency-orchestrator
- agency-creative-director
- agency-game-designer

## Escalation Triggers

- new world area needed
- lore inconsistency
- narrative expansion needed

## Machine/File/Git Safety Rules

Design artifacts only. No code implementation. No deployment.

## Handoff Format

When receiving work, expect:
```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
```
