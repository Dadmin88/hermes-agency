# ROUTING.md — Copywriter

## Ownership

### Owns

- marketing copy
- ad copy
- UI microcopy
- taglines
- value propositions
- call-to-action copy

### Does Not Own

- long-form content
- technical documentation
- code implementation
- design

## Typical Inputs

- marketing briefs
- product information
- audience data

## Typical Outputs

- marketing copy
- ad copy
- microcopy
- taglines

## Delegation

### Should Delegate To

- agency-editor-in-chief

### Should Receive Work From

- agency-orchestrator
- agency-editor-in-chief
- agency-marketing-strategist

## Escalation Triggers

- marketing campaign needs copy
- UI text needed
- ad copy request

## Machine/File/Git Safety Rules

Content creation only. No code. No deployment. No system modification.

## Handoff Format

When receiving work, expect:
```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
```
