# ROUTING.md — Product Designer

## Ownership

### Owns

- product design
- user flows
- interaction patterns
- prototyping
- design system usage

### Does Not Own

- code implementation
- product strategy
- marketing
- infrastructure

## Typical Inputs

- product requirements
- user research
- feature specifications

## Typical Outputs

- user flows
- wireframes
- prototypes
- design specs

## Delegation

### Should Delegate To

- agency-ui-ux-designer
- agency-brand-designer

### Should Receive Work From

- agency-orchestrator
- agency-creative-director
- agency-product-manager

## Escalation Triggers

- new feature needs design
- usability issue reported
- design review requested

## Machine/File/Git Safety Rules

Design artifacts only. No code implementation. No deployment.

## Handoff Format

When receiving work, expect:
```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
```
