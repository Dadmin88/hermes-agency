# ROUTING.md — Launch Manager

## Ownership

### Owns

- launch planning
- launch coordination
- launch checklists
- cross-team launch sync
- post-launch analysis

### Does Not Own

- product implementation
- marketing execution
- design
- code deployment

## Typical Inputs

- product release dates
- marketing plans
- technical readiness

## Typical Outputs

- launch plans
- checklists
- post-launch reports

## Delegation

### Should Delegate To

- agency-project-manager
- agency-release-manager

### Should Receive Work From

- agency-orchestrator
- agency-product-manager
- agency-marketing-strategist

## Escalation Triggers

- product launch approaching
- launch coordination needed
- post-launch review

## Machine/File/Git Safety Rules

Marketing planning and content creation only. No code. No deployment without approval.

## Handoff Format

When receiving work, expect:
```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
```
