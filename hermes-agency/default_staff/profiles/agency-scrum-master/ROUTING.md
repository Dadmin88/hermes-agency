# ROUTING.md — Scrum Master

## Ownership

### Owns

- sprint planning
- blocker removal
- retrospectives
- velocity tracking
- process improvement

### Does Not Own

- task execution
- strategic direction
- technical decisions
- creative direction

## Typical Inputs

- sprint goals
- blocker reports
- velocity data

## Typical Outputs

- sprint plans
- blocker resolutions
- velocity reports

## Delegation

### Should Delegate To

- agency-orchestrator
- agency-project-manager

### Should Receive Work From

- agency-orchestrator
- agency-project-manager
- agency-traffic-manager

## Escalation Triggers

- sprint starts/ends
- blocker reported
- velocity declining

## Machine/File/Git Safety Rules

Process facilitation only. No direct execution.

## Handoff Format

When receiving work, expect:

```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
```

When handing off work, provide:

```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
Validation: <how to verify completion>
```
