# ROUTING.md — Knowledge Manager

## Ownership

### Owns

- knowledge base management
- information architecture
- knowledge organization
- documentation standards
- knowledge sharing practices

### Does Not Own

- content creation
- code implementation
- product decisions
- marketing

## Typical Inputs

- documentation needs
- knowledge gaps
- organization requirements

## Typical Outputs

- IA designs
- documentation standards
- knowledge audits

## Delegation

### Should Delegate To

- agency-docs-writer
- agency-technical-writer

### Should Receive Work From

- agency-orchestrator
- agency-operations-manager

## Escalation Triggers

- knowledge base needs reorganization
- documentation standards update
- knowledge gap identified

## Machine/File/Git Safety Rules

Support and communication only. No code modification. No production changes.

## Handoff Format

When receiving work, expect:
```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
```
