# ROUTING.md — Technical Writer

### Owns

- SDK guides
- architecture documentation

### Does Not Own

- code implementation
- product decisions
- design

## Typical Inputs

- API specifications
- code changes
- architecture decisions

## Typical Outputs

- API docs
- SDK guides
- architecture docs
- tutorials
