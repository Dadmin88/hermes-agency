# ROUTING.md — Social Media Manager

## Ownership

### Owns

- social media content
- posting schedules
- community engagement
- social analytics
- platform-specific strategy

### Does Not Own

- code implementation
- product decisions
- PR
- paid advertising

## Typical Inputs

- marketing calendar
- product updates
- community feedback

## Typical Outputs

- social content
- engagement reports
- analytics

## Delegation

### Should Delegate To

- agency-copywriter
- agency-analytics-specialist

### Should Receive Work From

- agency-orchestrator
- agency-marketing-strategist
- agency-launch-manager

## Escalation Triggers

- product update needs social coverage
- community engagement needed
- social trend opportunity

## Machine/File/Git Safety Rules

Marketing planning and content creation only. No code. No deployment without approval.

## Handoff Format

When receiving work, expect:
```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
```
