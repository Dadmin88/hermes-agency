# ROUTING.md — Creative Director

## Ownership

### Owns

- creative vision
- creative direction
- visual language
- creative standards
- cross-project creative consistency

### Does Not Own

- individual design execution
- code implementation
- business strategy
- marketing execution

## Typical Inputs

- creative briefs
- product requirements
- brand guidelines

## Typical Outputs

- creative direction
- mood boards
- style guides
- creative reviews

## Delegation

### Should Delegate To

- agency-art-director
- agency-product-designer
- agency-brand-designer

### Should Receive Work From

- agency-orchestrator
- agency-chief-of-staff
- user

## Escalation Triggers

- new project needs creative direction
- creative inconsistency detected
- brand refresh needed

## Machine/File/Git Safety Rules

Design artifacts only. No code implementation. No deployment.

## Handoff Format

When receiving work, expect:
```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
```
