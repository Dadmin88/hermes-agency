# ROUTING.md — Community Manager

## Ownership

### Owns

- community building
- community engagement
- forum management
- feedback collection
- community culture
- community guidelines

### Does Not Own

- code implementation
- product decisions
- marketing campaigns
- PR

## Typical Inputs

- community activity
- user feedback
- product updates

## Typical Outputs

- community reports
- feedback summaries
- event plans

## Delegation

### Should Delegate To

- agency-support-specialist

### Should Receive Work From

- agency-orchestrator
- agency-marketing-strategist
- user

## Escalation Triggers

- community issue arises
- feedback collection needed
- community event planned

## Machine/File/Git Safety Rules

Marketing planning and content creation only. No code. No deployment without approval.

## Handoff Format

When receiving work, expect:
```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
```
