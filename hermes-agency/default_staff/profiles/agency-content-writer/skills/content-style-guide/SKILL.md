# Content Style Guide

## When to Use
When writing, editing, or reviewing any content — marketing copy, documentation, blog posts, or UI text.

## Prerequisites
- Understanding of the target audience
- Brand voice guidelines (if available)

## Steps

### Step 1: Establish voice and tone
- **Voice**: Consistent personality across all content (professional, friendly, technical)
- **Tone**: Adjusts based on context (formal for docs, casual for social)
- **Default**: Clear, direct, helpful. Avoid jargon unless the audience expects it.

### Step 2: Follow formatting rules
- Use sentence case for headings (not Title Case)
- Keep paragraphs short (3-5 sentences max)
- Use bullet points for lists of 3+ items
- Use numbered lists for sequential steps
- Bold key terms on first use
- Use code blocks for code, commands, or technical terms

### Step 3: Write clearly
- Lead with the most important information (inverted pyramid)
- Use active voice ("The system processes..." not "It is processed by...")
- Remove filler words (very, really, just, basically, actually)
- Use specific numbers instead of vague terms ("3 steps" not "a few steps")
- One idea per paragraph

### Step 4: Edit ruthlessly
- Cut words without losing meaning
- Replace complex words with simple ones
- Check for consistency (same term used throughout)
- Read aloud — if it sounds awkward, rewrite it

### Step 5: Apply brand consistency
- Use the same product/feature names throughout
- Match the established terminology
- Follow the brand's capitalization and punctuation rules
- Maintain the same level of formality

## Tool Usage
- `read_file` for reviewing existing content
- `write_file` for creating/editing content
- `search_files` for checking terminology consistency

## Pitfalls
1. Don't use jargon without explaining it
2. Don't write in passive voice
3. Don't use filler words
4. Don't mix terminology (pick one term and stick with it)
5. Don't skip editing — first drafts are never final

## Quick Reference
- Voice: Consistent personality
- Tone: Context-adjusted
- Format: Short paragraphs, bullet lists, sentence case
- Write: Active voice, specific, direct
- Edit: Cut, simplify, check consistency
