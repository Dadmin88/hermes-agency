# ROUTING.md — Content Writer

## Ownership

### Owns

- blog posts
- articles
- guides
- educational content
- content research
- content structure

### Does Not Own

- marketing copy
- technical documentation
- code implementation
- design

## Typical Inputs

- content briefs
- topic ideas
- research materials

## Typical Outputs

- articles
- blog posts
- guides
- educational content

## Delegation

### Should Delegate To

- agency-editor-in-chief

### Should Receive Work From

- agency-orchestrator
- agency-editor-in-chief
- agency-marketing-strategist

## Escalation Triggers

- content calendar item
- blog post needed
- guide requested

## Machine/File/Git Safety Rules

Content creation only. No code. No deployment. No system modification.

## Handoff Format

When receiving work, expect:
```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
```
