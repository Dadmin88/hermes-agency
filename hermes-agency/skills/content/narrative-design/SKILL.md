# Narrative Design

## When to Use
When creating stories, building worlds, developing characters, or managing narrative continuity.

## Prerequisites
- Understanding of the target genre and audience
- Access to existing lore and canon

## Steps

### Step 1: Establish story structure
Three-act structure:
- **Act 1 (Setup)**: Introduce characters, world, and conflict
- **Act 2 (Confrontation)**: Escalate stakes, obstacles, and character growth
- **Act 3 (Resolution)**: Climax and resolution

### Step 2: Design character arcs
For each main character:
- **Want**: What they're pursuing (external goal)
- **Need**: What they actually need (internal growth)
- **Flaw**: What holds them back
- **Arc**: How they change from start to end

### Step 3: Build the world
Document:
- **Setting**: Time period, geography, technology level
- **Rules**: Magic systems, physics, social norms
- **History**: Key events that shaped the current state
- **Factions**: Groups, their goals, and conflicts

### Step 4: Manage canon
- Maintain a canon bible — single source of truth
- Tag content by timeline and location
- Cross-reference new content against existing canon
- Resolve contradictions explicitly (don't ignore them)

### Step 5: Write dialogue
- Each character has a distinct voice (vocabulary, rhythm, patterns)
- Dialogue reveals character — what they say and don't say
- Subtext: characters rarely say exactly what they mean
- Read dialogue aloud — if it sounds unnatural, rewrite it

## Tool Usage
- `write_file` for creating narrative documents
- `read_file` for reviewing existing lore

## Pitfalls
1. Don't break established canon without explanation
2. Don't make characters consistent — give them contradictions
3. Don't over-explain — trust the reader's intelligence
4. Don't forget sensory details — show, don't tell
5. Don't write flat dialogue — every line should reveal something

## Quick Reference
Structure: Setup → Confrontation → Resolution
Character: Want vs Need, Flaw, Arc
World: Setting, Rules, History, Factions
Canon: Single source of truth, cross-reference, resolve contradictions
Dialogue: Distinct voices, subtext, read aloud
