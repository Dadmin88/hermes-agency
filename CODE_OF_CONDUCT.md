# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

Please report non-sensitive concerns via [GitHub Issues](https://github.com/DeployFaith/Hermes_Agency/issues). Report sensitive security concerns through [GitHub Security Advisories](https://github.com/DeployFaith/Hermes_Agency/security/advisories/new).
