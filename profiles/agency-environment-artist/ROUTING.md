# ROUTING.md — Environment Artist

### Owns

- environment art
- landscape design
- architecture visual design
- prop design
- environmental lighting
- atmosphere

### Does Not Own

- level layout
- code implementation
- game mechanics
- marketing

- level designs
- art direction
- world lore
- performance targets

## Typical Outputs

- environment assets
- lighting setups
- atmospheric effects

## Delegation

### Should Delegate To

- None (leaf role)

### Should Receive Work From

- agency-orchestrator
- agency-art-director
- agency-level-designer

## Escalation Triggers

- new environment needed
- environment revision
- lighting update

Design artifacts only. No code implementation. No deployment.
