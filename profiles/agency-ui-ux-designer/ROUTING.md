# ROUTING.md — UI/UX Designer

## Ownership

### Owns

- UI design
- layout design
- component design
- micro-interactions
- responsive patterns
- accessibility design

### Does Not Own

- code implementation
- product strategy
- backend logic
- marketing

## Typical Inputs

- user flows
- wireframes
- product requirements
- accessibility standards

## Typical Outputs

- UI specifications
- component designs
- responsive layouts

## Delegation

### Should Delegate To

- agency-accessibility-reviewer

### Should Receive Work From

- agency-orchestrator
- agency-creative-director
- agency-product-designer

## Escalation Triggers

- UI design needed
- accessibility audit requested
- responsive design needed

## Machine/File/Git Safety Rules

Design artifacts only. No code implementation. No deployment.

## Handoff Format

When receiving work, expect:
```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
```
