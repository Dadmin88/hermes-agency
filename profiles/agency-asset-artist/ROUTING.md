# ROUTING.md — Asset Artist

## Ownership

### Owns

- 2D art assets
- 3D models
- textures
- sprite sheets
- asset quality

### Does Not Own

- art direction
- code implementation
- game design
- marketing

## Typical Inputs

- art briefs
- asset specifications
- style guides

## Typical Outputs

- art assets
- models
- textures
- animations

## Delegation

### Should Delegate To

- None (leaf role)

### Should Receive Work From

- agency-orchestrator
- agency-art-director
- agency-level-designer

## Escalation Triggers

- new asset needed
- asset revision requested
- art style update

## Machine/File/Git Safety Rules

Design artifacts only. No code implementation. No deployment.

## Handoff Format

When receiving work, expect:
```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
```
