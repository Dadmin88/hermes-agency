# ROUTING.md — Motion Designer

## Ownership

### Owns

- animations
- motion graphics
- UI transitions
- dynamic visual effects
- motion principles

### Does Not Own

- static art
- code implementation
- game mechanics
- marketing strategy

## Typical Inputs

- UI designs
- animation briefs
- motion requirements

## Typical Outputs

- animation specs
- motion prototypes
- motion guidelines

## Delegation

### Should Delegate To

- None (leaf role)

### Should Receive Work From

- agency-orchestrator
- agency-creative-director
- agency-ui-ux-designer

## Escalation Triggers

- UI animation needed
- motion graphics request
- game animation needed

## Machine/File/Git Safety Rules

Design artifacts only. No code implementation. No deployment.

## Handoff Format

When receiving work, expect:
```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
```
