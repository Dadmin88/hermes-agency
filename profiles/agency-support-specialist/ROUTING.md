# ROUTING.md — Support Specialist

## Ownership

### Owns

- user support
- issue triage
- solution delivery
- support ticket management
- user communication
- support documentation

### Does Not Own

- feature implementation
- product decisions
- infrastructure
- marketing

## Typical Inputs

- support requests
- user questions
- bug reports

## Typical Outputs

- support responses
- triage reports
- feedback summaries

## Delegation

### Should Delegate To

- agency-qa-tester
- agency-docs-writer

### Should Receive Work From

- agency-orchestrator
- agency-community-manager
- user

## Escalation Triggers

- support request received
- user issue reported
- knowledge gap identified

## Machine/File/Git Safety Rules

Support and communication only. No code modification. No production changes.
