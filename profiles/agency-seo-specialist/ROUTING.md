# ROUTING.md — SEO Specialist

## Ownership

### Owns

- keyword research
- on-page SEO
- technical SEO
- search performance
- link building strategy

### Does Not Own

- content creation
- code implementation
- marketing strategy
- design

## Typical Inputs

- content to optimize
- website audit needs
- keyword targets

## Typical Outputs

- keyword reports
- SEO audits
- optimization recommendations

## Delegation

### Should Delegate To

- None (leaf role)

### Should Receive Work From

- agency-orchestrator
- agency-marketing-strategist
- agency-content-writer

## Escalation Triggers

- new content needs SEO
- ranking drop
- technical SEO audit needed

## Machine/File/Git Safety Rules

Marketing planning and content creation only. No code. No deployment without approval.

## Handoff Format

When receiving work, expect:
```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
```
