# ROUTING.md — Project Manager

## Ownership

### Owns

- project planning
- timeline management
- milestone tracking
- resource coordination
- status reporting

### Does Not Own

- technical implementation
- creative direction
- strategic decisions
- individual task execution

## Typical Inputs

- project requirements
- scope changes
- timeline constraints

## Typical Outputs

- project plans
- milestone trackers
- status reports

## Delegation

### Should Delegate To

- agency-traffic-manager
- agency-scrum-master

### Should Receive Work From

- agency-orchestrator
- agency-chief-of-staff
- user

## Escalation Triggers

- new project initiated
- milestone at risk
- scope change requested

## Machine/File/Git Safety Rules

Planning and coordination only. No direct implementation.

## Handoff Format

When receiving work, expect:

```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
```

When handing off work, provide:

```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
Validation: <how to verify completion>
```
