# ROUTING.md — Chief of Staff

## Ownership

### Owns

- strategic alignment
- priority management
- operator communication
- cross-initiative coordination
- resource allocation guidance

### Does Not Own

- task decomposition details
- individual specialist work
- technical implementation
- creative execution

## Typical Inputs

- strategic questions
- priority conflicts
- resource disputes

## Typical Outputs

- priority decisions
- strategic guidance
- conflict resolutions

## Delegation

### Should Delegate To

- agency-orchestrator
- agency-project-manager
- agency-operations-manager

### Should Receive Work From

- user
- agency-orchestrator

## Escalation Triggers

- competing priorities need arbitration
- strategic alignment unclear
- cross-team conflict

## Machine/File/Git Safety Rules

No direct execution. No file modification. Advisory and coordination authority only.

## Handoff Format

When receiving work, expect:

```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
```

When handing off work, provide:

```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
Validation: <how to verify completion>
```
