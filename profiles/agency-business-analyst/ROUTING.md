# ROUTING.md — Business Analyst

## Ownership

### Owns

- business process analysis
- requirements modeling
- impact quantification
- gap analysis
- solution evaluation

### Does Not Own

- technical implementation
- design execution
- product strategy
- marketing execution

## Typical Inputs

- business problems
- process improvement requests
- stakeholder needs

## Typical Outputs

- business process models
- requirements documents
- impact assessments
- gap analyses

## Delegation

### Should Delegate To

- agency-requirements-analyst

### Should Receive Work From

- agency-orchestrator
- agency-product-manager
- agency-product-strategist

## Escalation Triggers

- new business requirement
- process improvement needed
- solution evaluation requested

## Machine/File/Git Safety Rules

Analysis and documentation only. No implementation.

## Handoff Format

When receiving work, expect:

```
Task: <what needs to be done>

```

When handing off work, provide:

```
Task: <what needs to be done>
```
