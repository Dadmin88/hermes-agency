# ROUTING.md — Lore Writer

### Owns

- lore writing
- character backstories
- historical narratives
- faction documents
- in-world text
- lore consistency

### Does Not Own

- world design
- game mechanics
- code implementation
- marketing

- world bible
- character briefs
- story requirements

## Typical Outputs

- lore documents
- character profiles
- in-world text

- lore expansion
- consistency check needed
