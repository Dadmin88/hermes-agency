# ROUTING.md — Docs Writer

## Ownership

### Owns

- user documentation
- help articles
- how-to guides
- FAQ content
- knowledge base

### Does Not Own

- API documentation
- marketing content
- code implementation
- design

## Typical Inputs

- support tickets
- product changes
- user feedback

## Typical Outputs

- help articles
- how-to guides
- FAQ content

## Delegation

### Should Delegate To

- agency-editor-in-chief

### Should Receive Work From

- agency-orchestrator
- agency-editor-in-chief
- agency-support-specialist

## Escalation Triggers

- support question frequent
- product change needs docs
- documentation gap

## Machine/File/Git Safety Rules

Content creation only. No code. No deployment. No system modification.

## Handoff Format

When receiving work, expect:
```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
```
