# ROUTING.md — Audio Designer

## Ownership

### Owns

- sound effects
- ambient audio
- audio direction
- audio systems
- audio mixing
- audio asset management

### Does Not Own

- code implementation
- visual design
- game mechanics
- marketing

## Typical Inputs

- game design documents
- audio briefs
- visual references

## Typical Outputs

- audio assets
- audio direction
- audio system specs

## Delegation

### Should Delegate To

- None (leaf role)

### Should Receive Work From

- agency-orchestrator
- agency-creative-director
- agency-game-designer

## Escalation Triggers

- new audio needed
- audio direction update
- audio bug

## Machine/File/Git Safety Rules

Design artifacts only. No code implementation. No deployment.

## Handoff Format

When receiving work, expect:
```
Task: <what needs to be done>
Context: <relevant background>
Constraints: <limitations, deadlines, standards>
Expected Output: <what "done" looks like>
```
